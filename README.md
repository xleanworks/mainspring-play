# Mainspring

You are the tiny mechanic inside a giant clock tower that must strike every hour
or the town below falls apart. Run and jump across the gears, keep the rust
beetles off, and rewire gear ratios to power your defenses. Twelve hours to
save the clock.

Playable web build (Godot 4.3, nothreads export). Phone-first: play with one
thumb, touch works on desktop with a mouse too.
